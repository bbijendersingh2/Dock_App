SETUP (10 min)
1. Google Sheet banao > Extensions > Apps Script > Code.gs ka content paste > Save.
2. Deploy > New deployment > Web app: Execute as = Me, Who has access = Anyone > Deploy > "Web app URL" copy karo.
3. dock-app folder ko free hosting par daalo (Netlify Drop / GitHub Pages / Firebase Hosting). HTTPS zaruri hai.
4. index.html me API_DEFAULT = '' ki jagah URL paste karo (taaki users ko URL na daalna pade) aur host karo.
5. Users Chrome me link kholein > menu > "Add to Home screen / Install app". Icon home screen par aa jayega.
Note: Apps Script "Anyone" access = jiske paas URL hai wo data dekh/badal sakta hai. URL sirf dock team ko do.
